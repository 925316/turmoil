# turmoil

### Insert to toggle the panel.

In-level cheats:

- Level money
- Oil price lock
- Max pipe tiers
- Max rig speed
- Faster flow
- Grow / enrich wells

Build: run `build.bat` → `Build\Release\tmmod.dll`. Put in `BepInEx\plugins\tmmod\`.

Use [x64](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip) [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)
